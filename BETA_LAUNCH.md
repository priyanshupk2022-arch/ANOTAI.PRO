# ANOTAI Beta Launch Checklist 🚀

Ready to put AI to work? Follow this checklist for a smooth beta launch.

## 1. Merchant Onboarding
- [ ] **COGS Import**: Ensure the merchant has imported costs for at least 80% of active catalog.
- [ ] **Web Pixel Verification**: Confirm the "🛰️ System" status in settings shows Web Pixel as connected.
- [ ] **Billing Confirmation**: Merchant must authorize the $0/mo (Free Trial) or $29/mo plan.

## 2. Agent Configuration
- [ ] **Margin Guardian**: Set "Safety Zone" to 20% profit floor (Default).
- [ ] **Cart Sniper**: Enable email recovery sequence with 10% max discount.
- [ ] **Personal Shopper**: Enable "Bundle Proposal" mode.

## 3. Monitoring (First 48 Hours)
- [ ] Check `agent_actions` table in Supabase for any `error` statuses.
- [ ] Monitor Dashboard "Net Profit Impact" for real-time updates.
- [ ] Review Approvals queue for any stuck recommendations.

## 4. Feedback Collection
- [ ] Send "First Impression" survey to beta testers.
- [ ] Collect "Revenue Reporting" accuracy feedback.
