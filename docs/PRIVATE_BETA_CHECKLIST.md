# 🧪 PRIVATE BETA ONBOARDING CHECKLIST

Follow this checklist for every merchant invited to the ANOTAI Private Beta.

## 🟢 Pre-Installation
- [ ] Merchant has confirmed they have COGS (Cost of Goods Sold) data ready.
- [ ] Merchant is aware that AI will draft responses but not auto-send initially.

## 🔵 Installation & Setup
- [ ] Install app on Shopify store.
- [ ] Approve the **Beta Plan** ($0 during testing).
- [ ] Enable the **Storefront Widget** in Shopify Theme Editor.
- [ ] Complete the **Brand Playbook** (Tone of voice, Niche).

## 🟡 Core Configuration
- [ ] **COGS Import**: Upload CSV or sync from Shopify. Ensure >80% coverage.
- [ ] **Margin Guardian**: Set "Safety Zone" (Default 20% floor).
- [ ] **Cart Sniper**: Enable email recovery sequence.
- [ ] **Personal Shopper**: Enable skincare consultation mode.

## 🔴 Verification (The "First 48")
- [ ] **Test Execution**: Manually approve 1 Action Queue item and verify email delivery.
- [ ] **Margin Check**: Verify that "Net Profit Impact" on dashboard matches manual calculations.
- [ ] **Usage Monitoring**: Check the Internal Debug page for any errors for this store.
- [ ] **Feedback**: Schedule a 15-minute call with the merchant after 48 hours.
